# Sources

`/motion` combines what six open-source projects know about making motion video with an agent.
Code and wording were adapted only from the MIT-licensed projects. From the others, only general
ideas were taken; none of their text, code or assets are copied here.

| Project | Licence | What `/motion` takes from it |
|---|---|---|
| [latent-spaces/brag](https://github.com/latent-spaces/brag) (`brag-slim`) | MIT | inspect → plan → build → deliver flow, creative laws, tones, poster as frame 0, share copy |
| [dmtrKovalenko/fframes](https://github.com/dmtrKovalenko/fframes) (`fframes-video` skill) | MIT | the "no slop" rules, pacing, layout, type and easing numbers, recipes, checking a video you cannot watch; listed as an engine |
| [iart-ai/motion-skills](https://github.com/iart-ai/motion-skills) | MIT | the deliver-and-verify loop: seek to a time, screenshot, contact sheet, probe the encoded file's real spec; the catalogue of video kinds |
| [calesthio/OpenMontage](https://github.com/calesthio/OpenMontage) | AGPL-3.0 | idea only: choose a production pipeline by the kind of video |
| [blixvip/NullMotion](https://github.com/blixvip/NullMotion) | none stated | idea only: a plain black-and-white draft of every section before the polish |
| [feitangyuan/motion-web](https://github.com/feitangyuan/motion-web) | CC BY-NC 4.0 | idea only: springs over linear motion, and automated headless checks for dead frames |
